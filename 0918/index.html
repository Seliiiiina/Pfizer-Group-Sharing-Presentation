Problem. The review scope is too broad.“Any issues” does not define the required checks, including denominator, population filter, counts, percentages, sorting, and consistency.
Problem. The output format is unclear.“Tell me” does not define a usable review structure with findings, evidence, corrected values, severity, and next steps.
Problem. The finding is not confirmed.“Appears” does not confirm whether Placebo N=6 is wrong, what the correct value is, or which source supports it.
Problem. The impact is not quantified.“Some” does not identify the affected rows or show their current and corrected values.
Problem. The action is not specific.“Review with the programmer” does not specify what needs to be fixed, rerun, and reconciled.

Reusable Prompt · Clean Up Context
Before continuing, use the available conversation and files to create a concise Working Context: goal, source-of-truth files, confirmed rules, verified findings, open issues, superseded information, and next step. Preserve source references. Do not invent decisions or settle ambiguous conflicts; ask me about unresolved conflicts. Return only the brief; retrieve files as needed. Do not resume analysis.

Reusable Prompt · Create a Handoff
Create a concise handoff brief for continuing this task in a fresh conversation. Use six sections: Goal, Current State, Decisions, Open Issues, Ignore, and Next Step. Name the source-of-truth files and preserve verified values and source references. Keep unresolved issues open; do not invent decisions. Return only the brief, without resuming the task.
Reusable Prompt · Resume from a Handoff
Read this handoff brief and the referenced files before continuing. Confirm the current goal, accepted decisions, unresolved issues, and next step. Flag missing files or conflicts. Do not treat open issues as decisions or repeat completed work unless verification is needed. State your understanding and proposed next step first; wait for my confirmation before executing.

The core of output design is not simply making text shorter. It is rearranging information hierarchy for the person who will use it.
Example outputs · Same finding, different priorities

Programmer

Discrepancy. Placebo Any AE is 5 (83.3%) in the RTF; independent QC gives 4 (80.0%).

Evidence. ADSL SAFFL=Y gives N=5; ADAE contains four distinct safety subjects with AE.

Next step. Review population and counting logic, regenerate the table, and reconcile the output and log.

Statistician

Analysis rule. Use the safety population and count each subject once for Any AE.

Result. Placebo Any AE is 4/5 (80.0%), rather than the reported 5/6 (83.3%).

Review. Check the corrected table against the specification. This mock sample does not establish a treatment effect or causal relationship.

Leader

Deliverable impact. The AE table contains confirmed Placebo population and count discrepancies.

Required follow-up. Programming correction, a rerun, and QC reconciliation remain outstanding.

Decision needed. Confirm the correction owner and review timing before approving the deliverable.

Reusable Prompt · Define the Output Contract
Write for [Audience] to support [Purpose / Decision]. Prioritize [Key Information], use [Format], and stay within [Length]. Preserve verified values and source references. Separate findings from interpretation, list unresolved questions explicitly, and do not add unsupported conclusions.
Reusable Prompt · Output Repair
USERReorganize the verified AE QC findings into a review-ready brief. Keep the numbers unchanged, lead with the most important findings, separate evidence from interpretation, move supporting detail to the appendix, and clearly mark anything uncertain or unsupported by the source data.

Reusable Prompt · Evidence Check
USERReview each key claim and classify it as FACT, INFERENCE, or UNKNOWN based only on the available evidence. Treat a claim as FACT only when it is directly supported by the source data and cite that source; label it as INFERENCE when it is reasonable but not directly confirmed and state what still needs verification; use UNKNOWN when the available evidence is insufficient to determine the answer. Do not present inferences or unknowns as established conclusions.
